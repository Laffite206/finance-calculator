# Калькулятор личных финансов

## Описание проекта

Веб-приложение для учёта личных доходов и расходов пользователя.

Проект разработан на HTML, CSS и JavaScript и позволяет сохранять данные между сеансами с помощью localStorage.

## Основные возможности

* Добавление доходов и расходов.
* Выбор категории транзакции.
* Указание даты операции.
* Добавление комментария.
* Просмотр списка всех транзакций.
* Удаление транзакций.
* Фильтрация по типу, категории и дате.
* Подсчёт доходов и расходов.
* Расчёт текущего баланса.
* Текстовая диаграмма распределения расходов.
* Сохранение данных в localStorage.

## Используемые технологии

* HTML5
* CSS3
* JavaScript (ES6)
* localStorage

## Описание модулей

### app.js

Главный файл приложения. Отвечает за запуск программы, обработку событий формы и фильтрацию.

### storage.js

Сохранение и загрузка данных из localStorage.

### transactions.js

Добавление и удаление транзакций.

### filters.js

Фильтрация транзакций по заданным параметрам.

### statistics.js

Расчёт доходов, расходов, баланса и построение текстовой диаграммы.

### ui.js

Обновление интерфейса пользователя и отображение данных.

## Проверка работы

1. Ввести сумму транзакции.
2. Выбрать тип операции.
3. Выбрать категорию.
4. Указать дату.
5. Нажать кнопку «Добавить».
6. Проверить появление записи в таблице.
7. Обновить страницу и убедиться, что данные сохранились.
